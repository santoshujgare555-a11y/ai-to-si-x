## हा संग्रह कशासाठी आहे?

AI.TO.SI X च्या २५ भूमिका आणि एकत्रित Master Complete यांचे Instructions येथे बॅकअपसाठी आहेत. हे तयार केलेले नमुना मजकूर आहेत. Gemini मधील सध्याचे बदल, चॅट, अपलोड केलेले Knowledge किंवा सेटिंग्ज यांचा हा आपोआप घेतलेला export नाही.

Master Complete मध्ये एकच AI गरजेनुसार वेगवेगळ्या भूमिका घेतो. २५ स्वतंत्र प्रोग्रॅम एकाच वेळी चालत नाहीत. हे प्रकल्पाचे Design / Instructions आहेत; चाचणी केलेली स्वयंचलित सेवा नाही.

## मोबाईलवर Gemini मध्ये वापरणे

1. फोनच्या ब्राउझरमध्ये [Gemini](https://gemini.google.com/) उघडा आणि स्वतःच्या Google खात्यात प्रवेश करा.
2. Menu मधून Gems उघडा. गरज पडल्यास Settings and help मध्ये पाहा. New Gem किंवा तत्सम पर्याय निवडा.
3. एकत्रित पर्यायासाठी नाव `aitosix-master-complete` ठेवा आणि `agents/master-complete.txt` मधील पूर्ण मजकूर Instructions मध्ये पेस्ट करा.
4. स्वतंत्र भूमिका हवी असल्यास संबंधित group फाइलमधील त्या भूमिकेचे नाव वापरा. पेस्ट करण्याच्या दोन खुणांमधील मजकूर Instructions मध्ये द्या. Description साठी स्वतंत्र जागा दिसल्यास फाइलमधील Description वापरा.
5. स्क्रीनवरील Save / Create पर्यायाने जतन करा आणि साधा प्रश्न विचारून तपासा. मेनूची नावे खात्यानुसार बदलू शकतात. वेबवर तयार केलेला Gem त्याच खात्याच्या मोबाइल app मध्येही दिसू शकतो.

दुसऱ्या प्रकल्पासाठी वापरताना Instructions मधील मालकाचे नाव, ठिकाण आणि प्रकल्पाची माहिती स्वतःच्या माहितीनुसार बदला.

[Google चे Gems मार्गदर्शन](https://support.google.com/gemini/answer/15146780?co=GENIE.Platform%3DiOS&hl=en-KG)

## GitHub मध्ये ठेवणे आणि AI चालवणे यात फरक

GitHub वर या फाइल्स ठेवल्याने बॅकअप आणि शेअर करणे शक्य होते. फक्त upload केल्याने Gemini मधील Gem वेबसाइटला जोडला जात नाही किंवा वेबसाइटवर AI उत्तरे सुरू होत नाहीत.

GitHub Pages ही HTML, CSS आणि JavaScript साठी static hosting सेवा आहे. वेबसाइटवर प्रत्यक्ष AI उत्तरे हवी असल्यास स्वतंत्र जोडणी, सुरक्षित API वापर, चाचणी आणि शक्य खर्च यांचा आराखडा लागेल. या संग्रहात ती जोडणी केलेली नाही.

[GitHub Pages बद्दल अधिकृत माहिती](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)
